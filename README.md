# Vocab Review App

A personal vocabulary learning application built with Next.js.  
The app helps collect new English words and phrases, track their meanings and usage, and review them daily using a simple spaced repetition approach.

## Goals
- Capture new vocabulary from books, podcasts, and conversations
- Review words daily to improve long-term retention
- Keep the system simple and personal (MVP-focused)

## Tech Stack
- Next.js (App Router)
- React
- Tailwind CSS
- Node.js
- MongoDB (planned)
